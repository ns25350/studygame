## 1. アプリの概要と実装段階

学習を記録すると学習パワー（LP）とEXPを獲得し、LPでターン制ダンジョンへ挑戦する。ダンジョン報酬の石・素材・知識本を使って召喚や育成を進める。

基本の流れ：

1. 分数・時刻・タイマーで学習を記録。
2. LPとEXPを獲得。
3. キャラ・武器・知識本・スキルを育成。
4. ダンジョンに出撃し、4人の行動を選択。
5. 報酬を獲得して次の育成・召喚へつなげる。

現状は、ブラウザ内で完結するPWAのプロトタイプ。HTML/CSS/通常のJavaScriptによる静的アプリで、Reactなどのフレームワークは使っていない。ゲームデータは端末の `localStorage` に保存する。外部サービスとの自動同期はない。

## 2. UI・画風・端末要件

### 必ず引き継ぐ方針

- スマホ横画面を最優先。ユーザー端末の物理解像度は2424×1080。
- 物理解像度をCSSの表示領域と同一視しない。844×390、932×430、740×360 CSS pxも確認対象にする。
- 全画面背景をカメラ穴・ノッチ領域までつなげる。画面全体へsafe-areaのpaddingを掛けて背景を縮めない。
- 重要な文字・入力・操作には必要なセーフエリアを個別に持たせる。
- 左上に矢印付き「戻る」を統一して配置。ユーザーは画面の最も左上に近い位置を希望している。
- タイトル・ランク・全画面ボタン・石数などを、すべての画面に共通の大きな上帯として常設しない。
- 各画面は、その判断に必要な資源だけ表示する。
- 基本は1画面で完結。タブ・横スワイプ・ページ送りを使い、長い詳細・設定・高さ不足時は局所スクロールを許容する。
- 学習時間の数字はアプリ内の右側キーパッドで入力。時間入力のためにOSキーボードを開かない。
- タイマーは隅の時計アイコンから開く。
- メニューを1画面へ詰め込みすぎない。主役・現在の状態・次の操作を区別する。

### 画風

人物・背景・敵は、リアルな材質感と陰影を残したアニメイラスト調。NIKKEのようなイラストと質感の親和性、崩壊スターレイルのようなゲームの情報階層を参考とする。実在ゲームの素材や画面をそのままコピーする意図はない。

ホームや育成では正面、戦闘では行動中キャラの背面立ち絵を使う。キャラ画像は正面・背面を含む既存素材を利用している。ホームの実装は画像表示であり、Live2Dではない。

## 4. 学習記録・デイリー・ランク

### 学習記録

- 科目：数学、英語、国語、物理、化学、生物、地学、その他。
- 記録内容：日付、科目、教材・内容、分数、任意の開始・終了時刻。
- 教材・内容は自由入力で最大80文字。教材マスターから選ぶ機能は未実装。
- 入力方式は「分数で入力」「時刻で入力」。UIでは1〜720分の整数を受け付ける。
- 時刻はキーパッドで `0900` のように入力し、09:00と表示する。時刻入力は終了が開始より後の同日範囲。日付またぎの手入力には対応していない。
- キーパッド：数字0〜9、C（全消去）、1文字削除。PCでは数字・Backspace・Delete・Enterも使える。
- タイムラインは0:00〜24:00を横スクロール。時刻をタップするとその時間帯の入力へ移れる。時刻付き記録を配置する。
- 履歴から記録を削除できる。

記録1件あたりの獲得量：

```text
LP増加 = Math.round(学習分数 × 4 / 3)
EXP増加 = 学習分数
```

例：15分で20 LP、60分で80 LP、120分で160 LP。LPの丸めは記録1件ごとに行う。

削除時は、その記録に対応するLPとEXPを差し引く。どちらも0未満にしない。既に消費したLPも含めて残高から控除する。EXP減少によりランクが下がる場合があるが、育成済み装備レベルなどを自動で下げる処理はない。

### タイマー

時計アイコンの小パネルから開始し、停止時に記録する。開始時の科目・教材を使う。経過時間は保存した開始日時との差で計算するため、アプリを閉じている間も経過する。停止時に分単位へ四捨五入し、最低1分。日付またぎ・長時間は日付と720分上限に合わせて記録を分割する。

### デイリー

当日の学習を合計15分以上記録すると、手動で報酬を受け取れる。報酬は通常ダンジョン用の「調査証」5枚。1日1回で、受領時の残数は5枚に設定される。通常ダンジョン入場時に1枚消費し、その戦闘のLP消費が無料になる。次の日への切替時に前日の受領状態・残数をリセットする。

### ランク

```text
ランク = min(30, 1 + floor(EXP / 180))
```

| ランク | キャラ・武器レベル上限 |
|---|---:|
| 1〜4 | 20 |
| 5〜9 | 30 |
| 10〜14 | 40 |
| 15〜19 | 50 |
| 20〜30 | 60 |

ダンジョンクリアでもEXPが増加する。過去の「ランク8まで約2週間」などの育成ペース目標を、現コードの確定仕様と混同しない。

## 6. 戦闘・ダンジョン

### ダンジョン

| モード | 画面名 / 敵 | 敵HP | 敵の基準攻撃 | 入場・LP | 勝利報酬 |
|---|---|---:|---:|---|---|
| boss | 目標ボス / 未踏の公式 | 30,000 | 130 | 行動ごとにLP消費 | 石120、素材40、EXP60 |
| normal | 通常「資料庫」/ 頁喰らい | 9,000 | 90 | 調査証があれば1枚で無料。なければ行動ごとにLP消費 | 石45、素材12、知識本1、EXP25 |
| endgame | 高難易度「終極の書庫」/ 終極の観測者 | 70,000 | 220 | 入場20 LP、戦闘中無料 | 石180、素材60、知識本1、EXP100 |

各モードは現状1体の敵との戦闘。複数階層を進むダンジョンではない。高難易度は端末内の最少ターン記録と、その時点の累計学習時間を保存する。同ターンの記録では更新しない。公開ランキングは未実装。

### ターン進行

1. 「ターン開始」を押す。
2. コウイチロウ → アオイ → イオ → ミナトが1回ずつ行動。
3. 共有状態異常による継続ダメージ。
4. 敵が反撃。盾、HP、バフ残りターンを処理。
5. 次のターン開始待ちへ戻る。

各キャラが選べる技は通常攻撃・スキル1・スキル2・必殺技の4つ。必殺技もそのキャラの1回の行動を消費する。技を出した後に敵HPが0なら、残り行動や反撃へ進まず勝利する。

### LPとSP・ゲージ

- 基本消費LPは10 / 20 / 30から設定。
- 有料戦闘ではターン開始に「基本消費×4」以上の残高が必要。この段階ではLPを予約・消費しない。
- 各行動の消費LPは10 / 20 / 30から選べ、行動受付時に実際に消費する。
- 有料戦闘の効果倍率は消費LP÷10。無料戦闘では倍率1。
- LP不足なら行動を止め、消費を下げるか学習を記録して再開できる。戦闘途中の状態を保持する。
- SPはパーティー共通。初期5、上限10。通常攻撃でSP+1。
- 必殺ゲージはキャラごとに初期0、上限100。通常+28、スキル1+40、スキル2+25。武器のゲージ効果があれば加算。
- ゲージ100で必殺技が使え、使用時に0へ戻る。スキルLvでゲージ基本増加量は変化しない。

| キャラ | スキル1消費SP | スキル2消費SP |
|---|---:|---:|
| コウイチロウ | 5 | 2 |
| アオイ | 4 | 2 |
| イオ | 3 | 2 |
| ミナト | 3 | 2 |

通常攻撃と必殺技の消費SPは0。無料戦闘でもSP・ゲージ条件は残る。

### 共通HPとダメージ計算

パーティーは個別HPではなく共有HP・共有盾を持つ。

```text
最大共有HP = 1200 + 4人分の知識本HP加算
防御値 = 4人分の知識本防御加算の平均
敵の攻撃 = round(基準攻撃 × 1000 / (1000 + 防御値))
盾で防ぐ量 = min(敵の攻撃, 現在の盾)
共有HPへのダメージ = 敵の攻撃 - 盾で防ぐ量
```

現在の攻撃力Aと通常の攻撃倍率Mは次の通り。

```text
A = (キャラ基礎攻撃力 + キャラLv×12 + 武器攻撃力 + 知識本攻撃実数)
    × (1 + 知識本攻撃% + 武器攻撃%)
スキル倍率s = 1 + (その技のLv - 1)×0.06
LP倍率L = 有料時：消費LP/10、無料時：1
会心率 = min(95%, 30% + 知識本会心率 + 武器会心率)
会心倍率C = 会心時2.2、通常時1
M = L × s × C × (1 + 知識本の属性ダメージ加算)
```

各技のダメージ計算後に、対応する武器のダメージ加算とアオイの共有与ダメージバフを掛け、非負の整数へ四捨五入する。回復・盾には別の倍率を使い、会心を掛けない。

「虚ダメージ」はコウイチロウの追加ダメージとして表示・計算している。ただし現在は敵側の防御・属性耐性による減算自体がなく、防御無視と通常攻撃を別々の防御式で処理する仕組みはない。過去の検証用設定（会心50%、会心ダメ150%など）を現コードの基礎値と混同しない。

## 7. 各キャラのスキル

以下の数式ではA・s・L・Mを前項の定義として使用する。表の攻撃係数はスキルLv1時。武器ダメージ倍率と共有与ダメージバフは、表のダメージへ後から反映する。

### コウイチロウ — 質量・速さ・衝突

| 技 | 名前 | 効果 |
|---|---|---|
| 通常 | 運動の一撃 | `0.6A×M`。衝突状態なら`質量×速さ/20×M`を追加。初期質量の30%を減らす。質量が負になった場合は`速さ²×0.2×M`も追加し、質量・速さ・衝突状態を解除 |
| スキル1 | 一次元衝突 | 衝突状態に入る。初期質量・現在質量を`A×s×L`、速さを`50×s×L`に設定。再使用は加算ではなく再設定 |
| スキル2 | 加速する思考 | 速さを`10×s×L`加算 |
| 必殺 | 虚数の衝突 | `(10A + 質量×速さ×3/20)×M`。質量・初期質量・速さ・衝突状態を解除。専用カットインを再生 |

通常攻撃で減るのは現在質量の30%ではなく、初期質量の30%。スキル1で設定した場合、4回目の通常攻撃で負になる判定を行う。質量・速さにはスキル1や2の育成・LP倍率が乗り、追加ダメージ計算側にもMが乗る。この二段階の倍率を無断で簡略化しない。

### アオイ — 反応・支援

| 技 | 名前 | 効果 |
|---|---|---|
| 通常 | 触媒の一滴 | `0.75A×M` |
| スキル1 | 連鎖反応 | `1.7A×M`、共有状態異常を2追加 |
| スキル2 | 反応促進 | 共有与ダメージ倍率を`1+0.2×s×L`へ更新。残り2ターン。重ね掛けで加算しない |
| 必殺 | 反応の起爆 | `5.5A×M + 状態異常数×300×L`、状態異常を全消費 |

画面上には攻撃力強化という説明もあるが、実計算では最終与ダメージ倍率として作用する。

### イオ — 盾・防御

| 技 | 名前 | 効果 |
|---|---|---|
| 通常 | 地層の打撃 | `0.65A×M` |
| スキル1 | 堆積の盾 | `0.8A×M`、盾`180×s×L×武器盾倍率`を追加 |
| スキル2 | 岩盤の守り | 盾`130×s×L×武器盾倍率`を追加 |
| 必殺 | 大地の再生 | `4.5A×M`、HP`150×s×L×武器回復倍率`を回復 |

盾は残量へ加算。回復は最大共有HPを超えない。

### ミナト — 毒・回復

| 技 | 名前 | 効果 |
|---|---|---|
| 通常 | 芽吹きの一撃 | `0.7A×M` |
| スキル1 | 毒性の標本 | `0.9A×M`、共有状態異常を3追加 |
| スキル2 | 生命の循環 | HP`170×s×L×武器回復倍率`を回復 |
| 必殺 | 毒の共鳴 | `4.2A×M + 状態異常数×180×L`。状態異常を消費しない |

アオイの反応とミナトの毒は、内部では同じ `poison` カウンターを共有。4人の行動後に`状態異常数×90`の継続ダメージを与える。この継続ダメージにはLP・会心・武器・与ダメージバフ倍率を掛けない。

## 8. 武器・知識本・強化

### 装備の基本ルール

- キャラごとに武器1個＋知識本6冊を装備する。
- 武器はキャラの武器種と一致する所持品だけを装備可能。
- 知識本は対応する枠の所持品だけを装備可能。
- 同じ実物アイテムを複数キャラへ同時装備できない。
- 強化レベルはキャラの枠ではなく、アイテム固有IDに保存する。外して再装備しても残る。
- 戦闘が残っている間は武器・知識本の変更と強化を禁止。戦闘終了または撤退後に行う。
- 現実装ではキャラLv・スキルLv強化には同じ戦闘中禁止がない。これを共通制限へ変更する場合は仕様変更として扱う。

### 武器

27種類の定義があり、独立した画像は20枚。見習い版7種は通常版と画像を共有し、レア度表示で区別する。初期装備はキャラごとの訓練用B武器。

| レア度 | 武器LvをWとした攻撃力 |
|---|---|
| S | `70 + 12W` |
| A | `35 + 8W` |
| B | `5W` |

S武器の仮効果：

| 名前 | 武器種 | 効果 |
|---|---|---|
| 慣性の定規 | 刃器 | 通常攻撃ダメージ+18% |
| 蒼晶の試験管 | 触媒 | スキル1・2のダメージ+15% |
| 地層の羅針盤 | 測器 | 自身が付与する盾+25% |
| 星環のペン | 触媒 | 会心率+10ポイント |
| 黎明の定理 | 触媒 | 必殺ダメージ+25% |
| 観測者の杖 | 書杖 | 通常・スキルの必殺ゲージ獲得+8 |
| 白紙の刃 | 刃器 | 攻撃力+12% |
| 風化の針 | 測器 | 与ダメージ+12% |
| 芽吹きの書杖 | 書杖 | 回復量+25% |

A武器は与ダメージ+6%、対応する見習いB武器は+3%。訓練用B武器は追加効果なし。効果値は現状固定で、武器Lvは基礎攻撃力を増やす。武器合成・精錬・効果レベル強化は未実装。

### 知識本6枠

| 枠 | 名前 | 基礎版Lv0の効果 |
|---|---|---|
| 1 | 基礎の書 | HP+120 |
| 2 | 演習の書 | 攻撃力+35 |
| 3 | 証明の書 | 防御力+30 |
| 4 | 探究の書 | 会心率+5% |
| 5 | 復習の書 | 属性ダメージ+8% |
| 6 | 発見の書 | 攻撃力+6% |

| 版 | レア度 | 基礎効果の倍率 | 入手 |
|---|---|---:|---|
| 基礎版 | B | 1.0 | 初期装備 |
| 観測版 | A | 1.2 | 通常ダンジョン |
| 深淵版 | S | 1.5 | 高難易度 |

```text
知識本の効果 = 枠の基礎値 × 版の倍率 × (1 + Lv×0.05)
```

Lv0〜20。ダンジョンの知識本報酬は、累計獲得数に応じて6枠を順に配布し、通常は観測版、高難易度は深淵版になる。ランダムメインステータス、サブステータス、2/4セット効果は未実装。

### 強化コスト

| 対象 | 消費素材 | 1回の上昇 | 上限 |
|---|---:|---:|---|
| キャラLv | 10 | +1 | ランク別上限 |
| 武器Lv | 10 | +1 | ランク別上限 |
| 選んだ1つの技 | 20 | +1 | Lv10 |
| 選んだ1冊の知識本 | 20 | +4 | Lv20 |

通常攻撃を含む4つの技は独立して強化。スキル画面には技名、詳細、消費SP、ゲージ、現在と次のレベルの数値、素材コストを表示する。数値プレビューは10 LP時の基準。コウイチロウの必殺には「演出を見る」がある。

## 9. ガチャ

課金機能はなく、石はゲーム内報酬で獲得する。1回100石。現在は単発のみで、10連は未実装。

基本提供割合はS 5%、A 20%、B 75%。天井は各バナーで独立。S出現で天井回数を0に戻す。

### キャラ召喚

- 限定バナーはコウイチロウ・アオイ・イオの3つ。
- 60回目までにSが出なければ60回目でS確定。
- S時に75%でそのバナーの限定キャラ、25%で恒常Sの3人から抽選。
- 限定を外した場合、次のSはそのバナーの限定キャラ確定。
- Aは恒常Aの5人、Bは見習いBの5人から抽選。
- 属性・ロールは名前ごとに固定。属性選択UIを復活させない。
- 限定キャラを引くと対応する凸カウンターを増やす。表示は最大6。
- 現状、凸による戦闘性能上昇や恒常キャラの解放は実装していない。

### 武器召喚

- バナーは1つ。狙う武器を選択可能。
- 現在の選択肢は慣性の定規・蒼晶の試験管・地層の羅針盤・芽吹きの書杖の4種類。
- 50回目までにSが出なければ50回目でS確定。
- S時に50%で選択武器、50%でそれ以外のS武器8種類から抽選。
- 選択武器を外すと、次のSは選択武器確定。
- Aは通常武器7種、Bは対応する見習い武器7種から抽選。
- 入手ごとに別の所持アイテムIDを発行。重複しても合成せず別個体として持つ。

武器選択を変える操作では、現在の天井回数・確定フラグをリセットしていない。これはv18の実装挙動であり、変更する場合は明示的な仕様変更とする。

召喚演出は空から光が落ちる。Sは金、Aは紫、Bは青。結果と履歴にキャラの固定属性・ロール、または武器画像を表示。スキップ可能。

## 10. 必殺カットイン・その他の演出

コウイチロウの「虚数の衝突」に専用カットインを実装。

- 重りが腕へ引き寄せられる → 溜めて構える → 拳を手前へ殴り抜く。
- 約4.3秒、3.1秒時点の着弾で敵HPへダメージを反映。
- 立体的な質感の透過画像8ポーズと、遠近を持つ重り・カメラ・リングをCanvas 2Dで合成。
- 3D風の演出であり、動く3Dキャラモデル・WebGL・3D動画ではない。
- `requestAnimationFrame`で描画し、描画倍率は最大1.5。実機のfpsは未測定。
- 「演出を見る」はLP・SP・ゲージ・報酬を変更しないプレビュー。
- 演出中の戦闘操作を停止。スキップ・Esc・バックグラウンド移行・画像失敗・タイムアウトでも技を1回だけ確定する。
- 先にLP・ゲージなどを消費し、`pendingAction`を保存。着弾時にダメージを確定。再起動でも二重消費・二重ダメージ・二重報酬を防ぐ。
- 動きを抑える設定と効果音設定に対応。

他キャラには専用カットインをまだ実装していない。

通常戦闘には攻撃フラッシュ、ダメージ数値・会心表示、敵の溜めと飛来エフェクト、被弾時の画面演出、盾・BLOCK、HP減少表示がある。敵反撃も `enemyPhase` と適用済みフラグで二重ダメージを防ぐ。

`books`はダンジョンで得た知識本の累計であり、初期24冊を含む現在の所持数ではない。

### 保存形式

- ゲーム：`localStorage['study-arcana-prototype-v1']`。
- 端末設定：`localStorage['study-arcana-device-settings-v1']`。
- 端末設定は初期で効果音OFF・演出ON。OSの動きを減らす設定も参照。
- 主データ：LP、石、素材、EXP、記録、予定、デイリー、キャラ/技の育成、武器・本の所持品、装備、天井、凸、召喚履歴、タイマー開始、進行中戦闘、自己ベスト。
- 武器は `{id, template, level}`、知識本は `{id, slot, edition, level}`。
- `loadouts[キャラID] = {weapon: アイテムID, books: 6つのアイテムID}`。
- `skillLevels[キャラID][normal|skill1|skill2|ultimate]`。
- `weaponLevels` / `bookLevels` は装備品レベルから同期する互換データ。強化の実体は所持アイテム。
- 一時的な表示タブ・選択・戻る履歴・入力下書きなどは主に `ui` に持ち、すべてが永続保存されるわけではない。

設定からJSONを書き出し・読み込みできる。

```json
{
  "format": "study-arcana-save",
  "version": 1,
  "exportedAt": "日時",
  "state": {}
}
```

読み込みは形式・数値・配列・所有ID・装備枠・武器種・進行中攻撃などを検証する。ファイルは20 MiB以下。確認画面を出し、置き換える前に現在のセーブを書き出す。ゲームセーブへ音などの端末設定を一緒に含める仕組みはない。

### 既存データの移行

- 旧版の一括スキルLvを4技それぞれへ引き継ぐ。
- 旧版の一括知識本Lvを6枠へ引き継ぐ。
- 旧武器ガチャ履歴から重複を含む所持武器を復元。
- 旧知識本の累計から実物アイテムを補う。
- 同名の属性違い履歴を固定属性のキャラIDへ統一。
- 天井・確定フラグ・凸数・装備レベルを維持。
- 移行を再実行しても装備を重複生成しない。

## 14. PWA・技術構成

`viewport-fit=cover`、landscape指定、fullscreen/standaloneの表示設定、192/512pxアイコンとmaskableアイコンを持つ。AndroidのChromeでインストール成功済み。ホーム・戦闘から他画面までカメラ領域への背景拡張を行い、当該改修時にはユーザー実機でも拡張を確認している。

## 15. 改修時の確認と現在の限界

既存の確認コード：

```bash
node tests/verify-game.cjs
node tests/verify-ui-interaction.cjs

```
