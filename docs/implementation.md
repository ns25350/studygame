# 3Dターン制RPG版 v1.1

## 依頼との対応

ユーザーの「3Dターン制RPG」「崩壊スターレイルのような感じ」「必殺技に特殊カットインとダイナミックなカメラワーク」という方向に合わせ、最初のリアルタイム版からコマンド選択式へ変更しました。画面や素材の複製はせず、オリジナルの3D形状と演出を使用します。

参考は [添付のv18仕様書](reference-v18.md)。当初のリポジトリは空で、元のSitesソース・イラストは含まれていません。元のサイトや公開範囲は変更していません。

## 現在の戦闘ルール

- 「ターン開始」を押し、コウイチロウ → アオイ → イオ → ミナトが各1回行動。プレイヤー選択中に敵は自動行動しません。
- 各行動で通常・スキル1・スキル2・必殺の4択。必殺も1行動を消費し、割り込み技としては扱いません。
- 4人の終了後に `poison × 90` の共有状態異常ダメージ。それで倒せば敵の反撃を行いません。敵の攻撃は共有盾 → HPで受けます。
- アオイの与ダメージ倍率は2ターン。敵行動後に残りターンを減らします。
- SP初期5/上限10、通常SP+1、キャラ別ゲージ初期0/上限100。各技のSP・ゲージ獲得と、16技の数式は参考仕様のままです。
- 有料戦闘はターン開始に基本LP×4を確認。この段階では予約・消費せず、各行動の受付で10/20/30 LPを消費します。戦闘コマンド上でも消費を切り替えられます。
- 通常は調査証1枚で戦闘中のLP無料。高難易度は入場20 LPで戦闘中無料。訓練は消費・報酬なし。
- 高難易度は最少ターンを記録し、同ターンでは更新しません。旧アクション版の秒数ベストは `actionBest` に保持してから新記録を保存します。
- 移動・回避・攻撃範囲・時間式クールダウン・自動敵攻撃は廃止。4人を3D空間に並べ、行動キャラを前面に出します。

LP・EXP、ランク上限、デイリー、個体ごとの装備レベル、6枠の知識本、武器種・所有IDの制限、召喚の独立天井・確定・凸・履歴は維持しています。戦闘中の装備変更・装備強化は引き続き禁止します。

## 必殺の3Dカットイン

| キャラ | 固有の表現 | カメラ |
|---|---|---|
| コウイチロウ | 重りの周回・収束、踏み込み、衝突、広がる衝撃環 | 顔の寄り → 低位置の構え → 踏み込み追従 → 着弾の広角 |
| アオイ | 浮遊結晶、回転する反応環、収束・連鎖爆発 | 顔の寄り → 斜め上から旋回 → 結晶を追う移動 → 敵側からの引き |
| イオ | 大地の魔法環、複数の岩盤柱、再生の光 | 顔の寄り → 大地に近い低位置 → 高い俯瞰 → 地表から着弾を見る |
| ミナト | 開いた書、浮遊する葉、二重螺旋の蔓、生命の光 | 顔の寄り → 上昇 → 敵を見下ろす移動 → 螺旋を包む引き |

実際のThree.jsメッシュ・材質・照明を動かし、カメラ位置・注視点・画角・ロールをキャラごとのレールに沿って変化させます。通常の演出は約4.8〜5.2秒、着弾は72%地点。演出中は仲間と操作パネルを隠し、専用の上下帯・名前・技名・スキップを表示します。

キャラクター → スキルで全員の無料プレビューが可能。プレビューはLP・SP・ゲージ・敵HP・報酬を変更しません。動きを抑える設定またはOS設定では0.4秒の固定カメラで、回転・大きなエフェクトを抑えます。

## 一度だけ確定する仕組み

`queueAction` は現在キャラ・フェーズ・SP・LP・ゲージを検証。計算した結果を `turn.pending` に保存し、LP・SP・ゲージを一度だけ消費します。この時点では敵HPを変えません。

`applyPendingAction(id)` が着弾時に効果を一度だけ適用。`completePendingAction(id)` が次のキャラ、敵行動、または勝利へ進めます。両方ともID・適用済みフラグを確認し、重複呼び出しを無効にします。演出完了前の敵HP0も、検証済みの適用済み取引がある場合だけ保存として受け付けます。

スキップ、Esc、非表示化、ページ離脱、描画コンテキストの消失、タイムアウトは同じ確定処理へ接続します。再起動時は未完了の取引を復元して確定し、再消費しません。敵の反撃はフェーズとターン番号で二重処理を防ぎます。

## セーブ移行

保存キーとJSONの形式は最初の3D版から変更せず、localStorageと既存バックアップを引き継ぎます。`turn` がないアクション版の戦闘は、HP・盾・敵HP・SP・ゲージ・状態異常・質量・速さ・残高を維持してターン開始待ちへ移行。8秒だったバフ残時間は最大2ターンに換算します。新形式の保存を繰り返し読むと装備や報酬が増えることはありません。

元のv18の `study-arcana-prototype-v1` は別の保存領域のため読み書きしません。元ソースの移行処理がない状態でのv18互換インポートは未対応です。

## 技術と範囲

TypeScript / Vite / Three.js / Lucideによる静的PWA。全ローカル素材を本番Service Workerへ事前保存し、オフラインで遊べます。元のイラスト・3Dモデル・動画、Live2D、Google・Anki・AI・PDF連携、課金、自動同期、公開ランキング、恒常キャラの出撃解放は含みません。

新しいモデルへの差し替えは `src/world.ts`、固有カットインは `src/cinematic.ts`、戦闘ルールは `src/model.ts` で行えます。
