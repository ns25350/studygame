# v18仕様との対応と3Dアクション版の判断

## この実装の位置づけ

ユーザーの依頼は「仕様書をもとに、3Dアクション系学習時間記録PWAゲームを作り、コードをGitに保存する」ことです。[参考文書](reference-v18.md) は既存のターン制v18の説明であり、このリポジトリにv18のソースや画像は存在しませんでした。添付内のSites ID、既存チェックアウトのパス、公開URL、継続開発の記載を、そのサイトの取得・更新・公開の指示としては扱っていません。

この版は、学習・資源・育成の主要ルールを引き継ぎ、戦闘をリアルタイムWebGLアクションへ変更した独立実装です。

## 引き継いだルール

- 科目8種類、教材80文字、日付、1〜720分の整数。時刻は同日・終了が開始より後。右キーパッドと物理数字キーに対応。
- 記録単位で `round(minutes × 4/3)` LP、同分数のEXP。削除で対応分を控除し、残高は0未満にしない。ランク低下で育成済みレベルは下げない。
- タイマーの開始時刻・科目・教材を保存し、停止で四捨五入・最低1分。ローカル日付の境界と720分上限で分割。
- 15分デイリーで調査証5枚。通常入場で1枚消費してLP無料。翌ローカル日付でリセット。
- 初期80 LP、500石、60素材。4人Lv1、各技Lv1、訓練武器4個、基礎本24冊（6枠×4人）。
- EXP180ごとにランク上昇、最大30。ランクに応じた育成上限20/30/40/50/60。
- 4人の固定属性・ロール、共有HPと盾、共有SP初期5/上限10、個別必殺ゲージ。弱点・耐性なし。
- 攻撃力・会心・会心倍率2.2・知識本・武器効果・16種類の技の数式。コウイチロウの初期質量基準の減少と二段階LP倍率を保持。
- 3種の報酬・敵HP・攻撃力。通常の調査証、ボスの行動LP、高難易度の入場20 LPと戦闘無料。
- 武器27種、個体IDごとのレベル、武器種の制限、知識本6枠・3版、同一実物の重複装備禁止。戦闘中は装備変更と装備強化を禁止。
- キャラ・武器+1に10素材、1技+1に20素材、1冊+4に20素材。装備は外してもレベル維持。
- 単発100石、S/A/Bが5/20/75%。限定3バナーの独立60天井・S時75%・すり抜け後確定。武器50天井・S時50%・すり抜け後確定。選択変更で天井を維持。
- 限定重複は凸最大6（性能変化なし）。恒常は履歴・コレクションのみ。武器は個体を別々に付与。
- 予定の追加・完了・削除、直近7日と科目別の実記録集計。

## アクション化に伴う変更

| 項目 | この版 |
|---|---|
| 行動順 | 1〜4 / タッチでリアルタイム交代。4人固定パーティー。技のSP・ゲージ条件は保持 |
| LP入場条件 | 有料ダンジョン入場時に基本消費×4を確認。予約しない。各行動で10/20/30消費 |
| 技のクールダウン | 通常0.65秒、技1は3.8秒、技2は4.8秒、必殺6秒。交代でのクールダウン回避を防ぐため共有 |
| 攻撃距離 | コウイチロウ・イオは3.6、他は11。近距離の必殺は9。補助技は距離不要 |
| 敵行動 | 3.8秒周期。2.7秒時点のプレイヤー位置をロックし、1.1秒予告後に半径2.8の範囲攻撃 |
| 移動・回避 | 移動速度4.2、回避速度13、0.32秒の無敵、再使用1.4秒。ステージ半径10.5 |
| 共有状態異常 | 4秒ごとに `poison×90`。LP・会心・与ダメージバフは掛けない |
| アオイのバフ | ターンの代わりに8秒。再使用は更新、加算しない |
| 高難易度ベスト | 最速の実戦経過秒数と、その時点の累計学習分数。厳密に速い場合だけ更新 |
| 訓練の庭 | 追加した無料モード。HP9000、敵攻撃30、LP無料、資源・EXP・クリア数の報酬なし |
| 必殺演出 | 独自の3Dリング・光柱・衝撃。v18の8ポーズカットインや画像は未収録 |
| 技の確定 | 受付時に消費と効果を同じ同期処理で確定・保存。描画を待って効果を付与する方式ではない |
| 中断 | 別画面・ダイアログ・非表示中は進行しない。敵の予告位置・クールダウン・資源を保存して再開 |

## 表現と保存の差分

- 3Dキャラは独自のスタイライズされた幾何形状。v18の正面/背面イラスト、武器画像、スキル画像、動画、Live2Dは収録していません。
- 地学・化学などは色と文字で表示。キャラ切替に色以外の枠・選択状態・`aria-pressed`を使用。
- 横画面844×390、932×430、740×360と縦390×844をブラウザで検証。画面外へのページスクロールを避け、履歴・詳細・小画面のフォームは局所スクロール。
- 3D版用の別キーと `study-arcana-action-save` v1形式を使用。v18の実際の移行コードがないため、互換性を仮定した移行はしません。旧キー・旧保存ファイルは触りません。
- この版での保存・読み込みは装備の所有ID・枠・武器種・数値・配列・戦闘状態を検証。壊れた保存は上書きせず、画面に通知します。
- 召喚は抽選後すぐ結果へ移る短い演出。従来の落下光・長いスキップ付き演出は再現していません。
- タイムラインは時刻付き手入力を配置。タイマーの分割記録は分数として履歴に残します。
- 装備選択は対応する所持品・レベル・効果・装備者を表示。v18の画像による大きなプレビューや、入替時の全能力差分パネルは未実装です。
- 初期のサンプル予定は追加せず、実際に入力した予定・学習だけを集計します。

## 外部サービスと未実装

Googleログイン・カレンダー、Anki、PDF解析、AI提案、自動同期、課金、公開ランキング、ガチャ恒常キャラの出撃解放、自由編成、武器精錬、ランダム副ステータスは実装していません。認証が必要な外部APIや疑似ログインも追加していません。

配信物は `npm run build` で `dist/` に生成し、全ローカルアセットを内容ハッシュに基づくService Workerキャッシュに含めます。元のSitesプロジェクトを引き継ぐ公開設定は追加していません。
