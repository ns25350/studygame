## ブラウザで確認した操作

- 実WebGLコンテキストで3Dホームを描画。JavaScript例外なし。
- キーパッド・物理キーによる分数と同日時刻の記録、報酬計算、履歴・タイムライン・削除。
- デイリー受領と調査証による通常戦闘のLP無料化。
- 再読み込み後のタイマー復元、停止記録の一度だけの付与、モーダル内のキーボードフォーカス。
- キャラ・武器・独立した技の強化、召喚の獲得と履歴。
- 予定の追加・完了、入力テキストのHTMLエスケープ、実記録を使った分析。
- WASD移動・キャラ切替・攻撃による訓練クリア、戦闘中断・復元、有料勝利報酬の一度だけの付与。
- ジョイスティックのPointer Eventsによる移動、設定の演出軽減、撤退。
- 検証済みJSONの確認付きインポートとバックアップダウンロード、不正ファイルによる上書き防止。
- 844×390、932×430、740×360、390×844 CSS pxで主要画面、確定・戻る・閉じるへの到達と横方向のはみ出し防止。
- Service Workerの全アセット事前保存、ネットワークを切断した状態での再読み込みと学習記録。

## 範囲と制約

Chromiumのヘッドレス実行とソフトウェアWebGLでの確認です。タッチ操作はジョイスティックが使うPointer Eventsを通じて検証し、実機の指による操作、Android/iOSのインストールUI、実機FPS、ノッチ形状ごとの差は未検証です。実機での表示・性能調整は今後の確認対象です。

既存v18のソースや画像との照合、旧セーブの移行、外部サービス連携、公開サイトへの配信は実施していません。[実装差分](implementation.md) を参照してください。

## 再発防止として含めた修正

オフライン時にViteの `Vary: Origin` とモジュール取得の `Origin` ヘッダーがキャッシュ一致を妨げる問題を修正しました。検証済みの同一オリジンのアプリ素材だけを現在バージョンのキャッシュから検索します。認証リダイレクト・エラー・不正なMIME・アプリ以外のHTMLは事前保存しません。

小さい横画面でキーパッドの確定ボタンが隠れる問題を修正し、740×360を含むブラウザの実配置テストを追加しました。報酬計算・戦闘結果・読み込み検証は描画から分離してテストしています。
