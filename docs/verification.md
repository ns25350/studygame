## 戦闘と演出

- 行動選択を待っている間、敵HP・共有HP・行動数が勝手に変わらない。
- 4人が固定順で各1回行動し、敵の反撃が一度だけ発生して次ターンの開始待ちへ戻る。
- LP開始条件と行動ごとの実消費、SP不足・必殺ゲージの条件、状態異常・盾・ターン単位のバフを維持。
- 中断・再読み込みで現在のキャラと敵HPを復元。勝利報酬は再起動で増えない。
- 4人の必殺プレビューで実WebGLのカメラが動き、LP・ゲージ・HP・所持品を変更しない。
- 自然完走でportrait → charge → release → impact → recoveryの全カメラ段階を通り、ダメージを一度確定して次のキャラへ進む。
- スキップとEscを繰り返しても、消費・効果・報酬を重複しない。
- 着弾前・着弾後の中断データを復元しても同じ必殺を再消費しない。
- 動きを減らす設定では固定カメラ・短い演出で効果を一度確定する。
- 旧アクション版の保存データから、記録・所持品・天井・レベル・戦闘状態を維持して移行する。
