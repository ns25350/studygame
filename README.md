# 学習戦記 — STUDY ARCANA

学ぶ時間が、冒険の力になる。学習時間をLP・EXPに変換して、4人の観測者と星の書庫を攻略する、リアルタイム3Dアクション学習記録PWAです。

添付されたv18仕様を参考にした**新規の3Dアクション版**です。着手時の `ns25350/studygame` は空で、既存サイトのソース・イラスト素材はありませんでした。元サイトへの変更や公開操作は行っていません。仕様と実装の対応、変更点、未実装機能は [docs/implementation.md](docs/implementation.md) を参照してください。

## 起動

Node.js 22.12以上（検証環境：24.19.0）とnpmを使用します。データベース、APIキー、外部アカウントは不要です。

```sh
npm ci
npm run dev
```

開発サーバーはポート5173。本番ビルドとPWAの確認は次のコマンドで行います。

```sh
npm run build
npm run preview -- --port 4173
```

配信対象は `dist/`。HTTPS対応の静的ホスティングに配置してください。開発用のloopback配信を除き、Service WorkerとインストールにはHTTPSが必要です。PWAのキャッシュは本番ビルドのみで有効です。外部CDNや外部フォントは使用しません。

## 遊び方

1. 「学習記録」で科目・教材・分数（1〜720分）を入力。右のキーパッドを使用します。時刻入力と、閉じても経過する集中タイマーにも対応します。
2. 記録ごとに `round(分数 × 4/3)` LPと、分数と同じEXPを獲得。今日の合計15分で調査証5枚を手動受領できます。
3. 「訓練の庭」で無料練習。通常資料庫、目標ボス、高難易度へ挑戦し、報酬で育成・召喚します。
4. 戦闘を中断すると状態を保存。別画面から学習を追加して、LPを補充してから再開できます。

| 操作 | PC | タッチ |
|---|---|---|
| 移動 | WASD / 矢印 | 左のジョイスティック |
| 通常攻撃 | J | 通常攻撃ボタン |
| スキル1 / 2 | K / L | スキルボタン |
| 必殺技 | U（ゲージ100） | 必殺ボタン |
| 回避 | Space | 回避ボタン |
| キャラ切替 | 1〜4 | 左のキャラクター |
| 中断 / 戻る | Esc | 左上の戻る |

コウイチロウとイオは近距離、アオイとミナトは遠距離から攻撃できます。敵の赤い予告範囲から移動するか、無敵時間のある回避で攻撃を避けます。メニュー・非表示中の戦闘は進行しません。スマホ横画面を推奨し、縦画面にも対応しています。

## 保存とPWA

- 学習・育成・装備・天井・予定・進行中戦闘は `localStorage['study-arcana-action-v1']` に保存します。
- 音・演出設定は別キー `study-arcana-action-device-v1`。初期効果音OFF。OSの「動きを減らす」に対応します。
- 設定 → セーブからJSONの書き出し・読み込み。20 MiB上限、内容を検証し、確認後に現在のセーブをバックアップとしてダウンロードしてから置き換えます。
- v18の `study-arcana-prototype-v1` は読み書きしません。v18セーブのインポート・自動移行は未対応です。
- 初回オンライン読み込みでアプリと全アセットを事前保存。以後はオフラインで起動・記録・戦闘できます。
- 設定 → アプリ → 更新を確認 → 更新を適用。適用前にセーブします。
- Chromeのインストールメニュー、iOS Safariの共有 → ホーム画面に追加に対応。インストールの可否はブラウザによります。
- 記録は端末内のみ。ブラウザデータの消去に備え、定期的にJSONを保管してください。

## 検証

```sh
npm test           # ゲームルール・保存検証（Nodeテスト）
npm run build     # TypeScript型検証・配信用アセット生成
npm run test:e2e  # Chromiumで機能・レイアウト・オフライン検証
```

E2EにはChromiumが必要です。既定は `/usr/bin/chromium`、異なる場合は `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` を指定します。描画を実際に有効にしたブラウザで検証し、WebGLのソフトウェア描画では解像度・影を調整します。実機Android/iOSのFPS・インストール操作は、このクラウド環境では未測定です。

## 構成

```text
src/data.ts      キャラ・技・装備・ダンジョンの定義
src/model.ts     学習・育成・召喚・戦闘・セーブ検証
src/world.ts     Three.jsのステージ・キャラ・敵・演出
src/ui.ts        日本語画面・キーパッド・HUD
src/main.ts      操作・タイマー・ループ・保存・PWA更新
src/style.css    セーフエリア・横画面・縦画面・減速演出
public/          PWAマニフェスト・オリジナルアイコン
scripts/        Service Workerテンプレート・アイコン生成
tests/          ルールテスト・ブラウザ検証
docs/           参考仕様と実装上の判断
```

TypeScript / Vite / Three.js / Lucideを使用。3Dキャラクター、敵、ステージは独自のプロシージャル形状で構成し、既存ゲームの画像・モデルは使用していません。サードパーティー依存のライセンスは各パッケージに従います。

画面例：[ホーム](docs/screenshots/home.png) / [スマホ横画面の戦闘](docs/screenshots/battle-landscape.png)。検証結果は [docs/verification.md](docs/verification.md)、配信物のライセンス表記は [public/THIRD_PARTY_NOTICES.html](public/THIRD_PARTY_NOTICES.html) にあります。
