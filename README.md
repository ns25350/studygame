# 学習戦記 — STUDY ARCANA

学ぶ時間が、冒険の力になる。学習時間をLP・EXPに変換し、4人の観測者と星の書庫を攻略する**3Dターン制RPGの学習記録PWA**です。

4人の行動を選び、共有SP・盾・状態異常を組み合わせて戦います。必殺技には、顔のクローズアップ、構え、追従・旋回、着弾への引きをつないだキャラ別の3Dカットインがあります。キャラ・敵・ステージ・演出は独自の形状で制作しています。

元のv18仕様を土台とした独立実装です。着手時のリポジトリは空で、元サイトのソース・イラストはありませんでした。現在のルールと移行の方針は [docs/implementation.md](docs/implementation.md) を参照してください。

## 起動

Node.js 22.12以上（検証環境：24.19.0）とnpmを使用します。データベース、APIキー、外部アカウントは不要です。

```sh
npm ci
npm run dev
```

開発サーバーは5173。本番ビルドとオフラインPWAの確認は次のコマンドで行います。

```sh
npm run build
npm run preview -- --port 4173
```

配信対象は `dist/`。HTTPS対応の静的ホスティングに配置します。ローカル開発用配信を除き、インストールとService WorkerにはHTTPSが必要です。オフラインキャッシュは本番ビルドのみで有効です。外部CDN・外部フォントは使用しません。

## 学習と冒険

1. 学習記録の右キーパッドで、科目・教材・分数（1〜720分）を記録。開始・終了時刻による入力、アプリを閉じても経過する集中タイマーにも対応します。
2. 記録ごとに `round(分数 × 4/3)` LPと、分数と同じEXPを獲得。今日の合計15分で調査証5枚を手動受領できます。
3. 「訓練の庭」でLPを使わず戦闘を練習。資料庫・ボス・高難易度の報酬で育成・召喚を進めます。
4. LP不足や休憩時は左上から中断し、学習を追加してから続きのキャラで再開できます。

## ターン制の戦い方

「ターン開始」→ コウイチロウ → アオイ → イオ → ミナト → 状態異常ダメージ → 敵の反撃、の順です。選択中の時間制限はありません。移動・回避・攻撃距離・実時間のクールダウンはありません。

各キャラは通常攻撃・スキル1・スキル2・必殺技のいずれかを1回選択。必殺もそのキャラの行動を消費します。通常攻撃で共有SPを回復し、キャラ別ゲージ100で必殺が使えます。有料戦闘では10・20・30 LPを行動ごとに選択。ターン開始に基本消費×4以上が必要ですが、予約・消費は各行動の受付時に行います。

| PC操作 | 内容 |
|---|---|
| Space | ターン開始 |
| J / 1 | 通常攻撃 |
| K / 2 | スキル1 |
| L / 3 | スキル2 |
| U / 4 | 必殺技 |
| Esc | 戻る / カットインをスキップ |

スマホでは画面のコマンドをタップします。横画面を推奨し、縦画面にも対応。必殺演出はキャラクター → スキル →「必殺演出を見る」から無料プレビューできます。

- コウイチロウ：重りを引き寄せ、低いカメラから衝突を追う「虚数の衝突」。
- アオイ：浮遊結晶と反応環を旋回して追う「反応の起爆」。
- イオ：岩盤の隆起を低位置から俯瞰へつなぐ「大地の再生」。
- ミナト：開いた書と生命の螺旋を上昇して追う「毒の共鳴」。

演出中の操作をロックし、着弾時に効果を確定します。スキップ・非表示化・再読み込み・描画の中断でも、消費・ダメージ・報酬を重複させません。動きを抑える設定では固定カメラと短い演出を使います。

## 保存・更新

ゲームデータは `study-arcana-action-v1`、端末設定は `study-arcana-action-device-v1` のlocalStorageに保存します。キーを維持して、最初に作ったアクション版の記録・育成・所持品・天井・戦闘HPを引き継ぎます。旧アクション戦闘は、同じ残高・状態から次のターン開始待ちへ移行します。

設定 → セーブからJSONの書き出し・読み込み。20 MiB上限、数値・装備・進行中の技を検証し、確認後に現在のセーブをバックアップとしてダウンロードしてから置き換えます。ブラウザのデータ削除に備え、定期的にJSONを保管してください。元のv18の別キーには触りません。v18形式のインポートは未対応です。

初回オンライン読み込みで本体と全ローカル素材を事前保存し、以後オフラインで起動・学習・戦闘が可能。設定 → アプリから更新確認・適用。Chromeのインストールメニュー、iOS Safariの共有 → ホーム画面に追加を利用できます。複数端末の自動同期、Google・Anki・AI連携は未実装です。

## 検証と構成

```sh
npm test
npm run build
npm run test:e2e
npm run format:check
```

E2EはChromiumを使い、既定は `/usr/bin/chromium`。`CHROMIUM_PATH=/path/to/chromium` で変更できます。実機Android/iOSのFPS・インストールUIはクラウドの検証対象外です。

| ファイル | 内容 |
|---|---|
| `src/model.ts` | 学習・育成・召喚・ターン制・保存・技のトランザクション |
| `src/cinematic.ts` | 4人の3D必殺エフェクト・カメラレール |
| `src/world.ts` | Three.jsのステージ・キャラ・敵・演出再生 |
| `src/ui.ts` / `src/main.ts` | 日本語画面・操作・記録・戦闘進行・PWA更新 |
| `src/style.css` | 横/縦画面・セーフエリア・コマンド・カットインUI |
| `src/data.ts` | キャラ・技・武器・知識本・ダンジョン定義 |
